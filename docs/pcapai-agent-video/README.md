# pcapAI Agent 视频前期制作包

## 定位

本视频面向内部汇报，时长控制在 100-120 秒。核心叙事不是“AI 很强”，而是：

> 多节点抓包排障难以串证据，pcapAI Agent 用确定性工具和 Agent 编排，把抓包变成可复核的证据链。

## 交付内容

- `voiceover.md`：约 115 秒中文口播稿。
- `bgm-prompt.md`：BGM 生成提示词，中英文版本。
- `shot-plan.md`：按时间轴拆分的镜头规划。
- `visual-direction.md`：Data Drift 风格方向和关键帧提示词。
- `screenshot-plan.md`：真实 pcapAI 截图采集清单与用途。

## 默认规格

- 比例：16:9
- 分辨率：1920x1080
- 风格：Data Drift
- 语气：克制、技术、内部汇报
- 结构：痛点 → 为什么需要 pcapAI Agent → 架构 → 亮点和价值 → 案例 → 总结
