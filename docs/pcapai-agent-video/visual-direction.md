# Data Drift 视觉方向

## 视觉目标

画面要像真实的网络排障工作台，而不是抽象 AI 海报。核心观感是：深色数据空间、证据链流动、协议节点被逐步点亮。

## 色彩

- 背景：`#0a0a0a`
- 主高亮：cyan `#06b6d4`
- 次高亮：purple `#7c3aed`
- 异常提示：amber `#f59e0b`
- 正文文字：接近冷白，不使用纯白大面积铺满

## 字体建议

- 标题：细长、未来感无衬线，字重偏轻。
- 数据和过滤器：等宽字体，开启 tabular numbers。
- 正文字幕：清晰优先，避免过细导致视频压缩后发虚。

## 动效方向

- 数据路径用细线逐段点亮。
- pcap 文件进入 case graph，再汇聚为 QueryRun。
- 协议适配器以节点形式依次激活。
- 证据卡滑入，但不要像营销卡片墙。
- 异常只在关键点用 amber 提醒，不用大面积红色。

## 反向约束

- 不要抽象 AI 大脑。
- 不要机器人形象。
- 不要赛博朋克街景。
- 不要大面积紫蓝渐变。
- 不要把画面做成普通 SaaS 营销首页。
