壹 判断 · VERDICT
本次访问中断的根因是 DNS 解析故障引发的级联服务降级。客户端对 api.saas-portal.io 的解析在 22:13:22 返回 SERVFAIL（rcode 2），应用退化到陈旧缓存地址 10.0.8.1， 该地址已不再承载服务，导致后续 HTTP 请求集中收到 503，并伴随握手后 12 次 RST 复位。
DNS SERVFAIL → 陈旧缓存 IP → TCP 握手后 RST ×12 → HTTP 503 ×9
贰 证据 · EVIDENCE
共 4 张可回溯证物。DNS 层：frame 14 响应 rcode=2、 frame 27 无应答超时。TCP 层：5 个会话在 SYN→SYN/ACK→ACK 完成后 0.3s 内收到对端 RST。 HTTP 层：9 个事务返回 503、3 个返回 502，6 条 L7→TCP 确定性关联 将 HTTP Host 绑定到承载它的 TCP 流。
叁 反证 · COUNTER-EVIDENCE
已排除「网络丢包」假设：未观察到重传前的 duplicate_ack 堆积， RTT 平稳（均值 1.2ms）。已排除「服务端瓶颈」：未见 Zero Window。当前仅单点（客户端侧）抓包， 无法确证 RST 来自服务端还是中间设备，需服务端侧抓包补证。
